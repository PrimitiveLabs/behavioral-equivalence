# Emission-aware learned-state verification

Status: implemented finite-model construction with regression and exact-rational tests. Learning transitions from human sequences and a final certificate-aware compression experiment remain open.

A history encoder and discretizer produce K predictive states. Each state has a binary outcome distribution E(s,y). A transition law T(s,y,t) describes the next predictive state after observing y, under a fixed documented exposure policy/environment. These are fitted model quantities, not proven cognitive states or an automatically valid human Markov process.

`decision_model.decision_chain` constructs three labeled states per predictive state: pending(s), negative(s), and positive(s). Pending(s) transitions to its outcome state with probability E(s,y). That outcome state transitions to pending(t) with probability T(s,y,t). This separates the observable emission from the latent-state update and makes both available to the existing label-preserving quotient certificate.

A proposed latent partition lifts into three separate block families, one for each label. Its discrepancy is checked against the actual quotient rows for every pending and outcome state. Differences in E are therefore included directly in epsilon. An initial pending state and its abstract pending block are related with matching labels; no hidden outcome-dependent initial mixture is required. One future decision exposes its outcome after one graph transition. H future decisions require 2H-1 graph transitions from a pending initial state. The existing coupling theorem applies at that graph horizon. Report this convention whenever comparing decision horizons with error bounds.

The initial empirical quantization baseline clusters frozen GRU/history and current-tab embeddings and averages training-only teacher probabilities. Its clusters at different K are separately fitted and are not automatically nested quotient partitions. That baseline has no label-preservation or transition certificate. Preserving its next-outcome likelihood alone does not establish future-path equivalence.

For the proposed certified method, freeze a starting discrete model, estimate outcome-conditioned transition rows using reserved data, generate candidate nested latent merges, lift them to labeled graph partitions, and reject merges exceeding the uniform model-level discrepancy budget. Use validation-only operating-point selection, independent calibration when coverage needs it, and held-out human outcomes for predictive fidelity. Compare against the same starting discrete model as well as continuous strong predictors. Check conditional history dependence and nonstationarity; a sound quotient of a misspecified model remains a statement about that model.

## Nested certified compression implementation

`learned_abstraction.certified_latent_refinement` accepts a partition of a frozen parent latent state space, lifts it into the three observation stages, and refines it until the actual normalized binary-rational one-step radius meets the supplied budget. A single latent partition controls all three stages. Each abstract state therefore contains parent states, rather than representing an independently refitted clustering. Integer certificates preserve the positive and negative outcome labels. Forecasts use the certified quotient's one-step positive-emission probability for each parent latent state.

If a merge fails, the implementation splits a witnessed latent state. If a singleton origin witnesses error caused by rounded aggregation into merged successors, it refines a remaining nontrivial latent block. Every unsuccessful iteration increases the latent state count. The singleton partition has zero exact radius, so this finite procedure terminates. This gives a correct, potentially conservative refinement algorithm, not an optimal-compression algorithm. The engineering tests cover an exactly redundant emission model and a pair with distinct emissions that must split.

This implementation is ready for estimated learned emission/transition inputs. No real-data certified compression result follows from its synthetic fixtures. The five independent K-state quantizations in the pilot are unverified baselines and do not become nested certificates retroactively.

When estimating transitions from timestamp bundles, document an outcome-independent representative-exposure sampling design or an explicitly different bundle outcome model. Do not order tied events by their feedback. A uniform random representative per bundle defines a narrower exposure-response estimand and must use the same cases for all comparisons. No label-dependent deterministic representative is permitted. Feedback labels describe eventual recorded responses indexed by exposure decisions, not necessarily their real-time availability. Only feedback available under the prespecified timing policy enters the history encoder. Conditional transition factorization over eventual outcomes does not establish a causal intervention model or a human Markov state.
